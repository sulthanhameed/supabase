# 🥢 Khang Chinese Restaurant & Dimsum

Full-stack food ordering platform — **React frontend** + **Express REST backend** + **PostgreSQL**, joined by one connection file.

```
├── render.yaml       ← Render Blueprint (backend + Postgres)
├── connect.js        ← ★ THE JOIN FILE: backendUrl / frontendUrl (both apps read it)
├── frontend/         ← React (Next.js) app → deploy on Vercel   [generated by `npm run export:frontend`]
├── backend/          ← Node.js + Express REST API → deploy on Render
├── database/         ← PostgreSQL schema.sql + seed.sql
├── src/, public/     ← source of the frontend (also runs here as the all-in-one preview)
└── scripts/          ← export-frontend.mjs, connect.mjs
```

## Join frontend ↔ backend (one file)
Open **`connect.js`** and fill:
```js
backendUrl:  "https://khang-backend.onrender.com",   // your Render URL
frontendUrl: "https://khang.vercel.app",             // your Vercel URL
```
Then `npm run connect` — it writes `NEXT_PUBLIC_API_URL` into `frontend/.env.production` and `FRONTEND_URL` / `OWNER_EMAIL` into `backend/.env`.
The frontend's `next.config.ts` and the backend's `src/config.js` also read `connect.js` directly, so filling the file and redeploying is enough.
Env vars set on Vercel/Render always take priority.

## Commands (repo root)
| Command | What it does |
|---|---|
| `npm run dev` | Frontend + built-in API on http://localhost:3000 (uses `DATABASE_URL`) |
| `npm run backend:setup` → `npm run backend` | Install backend deps, then run the Express API on http://localhost:4000 |
| `npm run export:frontend` | Regenerate the standalone `frontend/` folder from `src/` |
| `npm run connect` | Push URLs from `connect.js` into both apps' env files |
| `cd backend && npm run check -- <backendUrl> <frontendUrl>` | Test health + CORS between the two |

## Deploy (exact settings in **DEPLOY.md**)
| Part | Host | Root Directory | Build Command | Start Command | Required env |
|---|---|---|---|---|---|
| Backend + DB | Render (Blueprint: root `render.yaml`) | `backend` | `npm run build` | `npm start` | `DATABASE_URL`, `JWT_SECRET`, `FRONTEND_URL`, SMTP_*, RAZORPAY_* |
| Frontend | Vercel (or Render) | `frontend` | `npm ci && npm run build` | `npm start` (Render only) | `NEXT_PUBLIC_API_URL` |

Node **22** is required (`.nvmrc`). Use **npm** (`package-lock.json`); a matching `yarn.lock` is included for hosts that default to yarn.

Verify: `https://<frontend>/api/connection` → `{"ok":true}`. Admin login: `admin@khang.com` / `admin123`.
